
# AI Prompts & Learning Documentation

## Project: Registration Wizard

### 1. Project Setup
**Prompt:**
> Help me create a React registration wizard using Vite with three steps: Personal Information, Account Details, and Review & Submit.

**Learning:**
I learned how to create a React project using Vite and install the required dependencies.

### 2. Form Validation
**Prompt:**
> Implement form validation using React Hook Form and Zod. Validate email, password length, and confirm password matching.

**Learning:**
I learned how schema-based validation works and how to display validation messages.

### 3. Multi-Step Navigation
**Prompt:**
> Create a three-step registration wizard with Next and Back buttons while preserving form data between steps.

**Learning:**
I learned how to manage the current step using React state and preserve form values.

### 4. Progress Bar
**Prompt:**
> Add a progress bar that displays the current step and percentage of completion.

**Learning:**
I learned how to calculate progress dynamically using the current step.

### 5. Debugging
**Prompt:**
> Help me troubleshoot errors in my React registration wizard and explain how to identify the cause.

**Learning:**
I learned how to inspect terminal errors, browser console messages, and Vite's hot module replacement updates.

### 6. Responsive Design
**Prompt:**
> Create a professional and responsive CSS design for a three-step registration wizard.

**Learning:**
I learned how to use CSS layouts, media queries, spacing, colors, and responsive styling.

### 7. Final Testing
**Prompt:**
> Provide a QA checklist for testing a registration wizard, including validation, navigation, data retention, and form submission.

**Learning:**
I learned how to test form functionality and verify that user data is retained when navigating between steps.
